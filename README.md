# White-Lotus-Scanner
© Developed by Red Lotus, WL is a Lotus+ Utility that scans files from fetched, advanced generic bypass detections.
![image](https://github.com/user-attachments/assets/bb769ae0-2b21-437b-8970-f8034c481984)


# → The Scanner

1. WhiteLotus.exe is coded in Python, compiled using PY2EXE.

2. Executable requires a list of file paths in order to conduct its scanning operation. Preferred paths file extension is .csv, however in the selection menu you can switch it to a .txt.

3. As a free utility the scanner is limited to ASCII characters recognition, UTF-8 encoding. It will break if a Unicode character is detected.

4. Make sure all of the files provided are in quotes. You can either use online resources to add quotes to the paths or use notepad's default "Edit All" function.

# → Usage

1. Execute WhiteLotus.exe as Administrator (or elevate via CMD) and select a .txt / .csv dump containing file paths.

2. Scan results will output a .csv file. Readable using Timeline Explorer.

   ![image](https://github.com/user-attachments/assets/57faae4f-23c4-48d9-9d07-619d938e8aac)

# → Paths Creation

1. There are numerous ways of creating a .csv / .txt that contains file paths. Search Everything Export function is one of them.

2. View other tools and methods of Red Lotus [ discord.gg/redlotus ] to understand paths acquisition.
